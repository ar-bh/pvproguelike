# RogueScope
## currently called on Github "pvproguelike" but will be changed upon more progression


RogueScope is going to be a PVP Roguelike game (hence the name) inspired by Popular titles such as Fortnite, Counter Strike 2, Marvel Rivals, and Risk of Rain 2.

## Gamemodes:
(not yet of course)
- battle royale (inspired by Fortnite)
- Team gamemodes (inspired by Marvel Rivals)
- 1v1 duel (inspired by Brawl Stars? idk)
